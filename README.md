# OCR Project

## 📌 Overview
This is an **Optical Character Recognition (OCR) Project** built using Python. It extracts text from images and provides a structured output. The project utilizes libraries like **Tesseract OCR** for text extraction and supports multiple image formats.

## 🚀 Features
- Extract text from images
- Supports multiple file formats (JPG, PNG, etc.)
- Easy-to-use command-line interface
- Well-organized script structure

## 🗂 Project Structure
```
OCR_Project/
│── scripts/
│   ├── main.py          # Main script for running OCR
│   ├── image_processor.py # Handles image processing
│   ├── text_extractor.py  # OCR logic using Tesseract
│── requirements.txt     # Dependencies
│── README.md           # Project documentation
│── .gitignore          # Ignore unnecessary files
```

## 🔧 Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/aryanshahare1/OCR_Project-.git
   ```
2. Navigate to the project folder:
   ```bash
   cd OCR_Project
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Install **Tesseract OCR**:
   - Download and install from [here](https://github.com/tesseract-ocr/tesseract)
   - Add Tesseract to system environment variables

## 🚀 Usage
Run the project using:
```bash
python scripts/main.py --image path/to/image.jpg
```
